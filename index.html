How to go live

Set up the signal path outside this dashboard.

1. Connect destinations. Use official OAuth or copy the stream key from each platform's live setup.
2. Set up OBS or a VPS restreamer. Add the ingest server and key in your encoder. For multi-platform output use a restreaming service or relay you control.
3. Start your broadcast in the encoder. This dashboard can organize your session, but cannot send the video on its own.

Hosting & payments

Free static hosting; integrations need secure services.

Host the dashboard free using GitHub Pages settings. Actual multistreaming requires OBS/VPS or a supported service. Direct M-Pesa collection requires a payment provider such as IntaSend or PlusPesa and a secure backend—never expose provider secrets in this page.
